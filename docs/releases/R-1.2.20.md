# ProSkillAPI R-1.2.20 (pre-release)

Adds optional skill damage and healing handlers for SX-Attribute, the
`SX-Attribute.enabled` configuration gate (disabled by default), and a Lore
set-bonus snapshot event. Includes the equipment skill binding configuration
and listener required by these snapshots.

Use with SX-Attribute 4.0.0-beta.12 and MCCore 3.0.1. Install the shaded JAR.
Both plugins must enable their respective integration switches.

## Validation and limitations

- The preceding implementation built and enabled together on Paper 1.20.6.
- The previous Mineflayer matrix report tested an older ProSkillAPI without
  SX-Attribute; it is not evidence of end-to-end integration correctness.
- Full health authority, reload rollback, source accounting and combat numeric
  assertions remain incomplete. Healing currently handles player casters only.
- The external damage handler runs before SkillDamageEvent; existing event
  listeners can therefore be bypassed while the bridge handles damage.
- This is an experimental release, not a claim of completed plugin unification.
