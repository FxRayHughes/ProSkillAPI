# ProSkillAPI R-1.3.0

## 技能系统扩展

- 增加技能流程控制、分组执行、信号传递、技能调用与节流节点。
- 增加护盾授予、调整、读取、移除及护盾状态触发器。
- 增加经济、经验、飞行、氧气、世界时间、朝向、距离和玩家状态相关节点。
- 增加技能结果事件、技能接受/拒绝、冷却就绪、治疗、生效和等级变化触发器。
- 扩展动态技能注册、组件扫描和运行时状态处理，并补齐节点注解与编辑器字段说明。

## 跨版本与物品兼容

- 1.12.2 的耐久度路径不再链接高版本 `Damageable` API。
- 新增独立 1.14 桥接模块，`CustomModelData` 与耐久度由对应版本模块直接调用，主工程不再通过反射访问这些 Bukkit API。
- 保留 1.12.2 的旧式 `plugin.yml` 兼容方式，并移除只在 1.13+ 才能识别的 `api-version` 声明。
- MCCore 运行时依赖固定为 3.0.6。

## 编辑器

- 编辑器支持结构化字段、地图字段、配置设置、自动保存设置和串行保存队列。
- 粒子值以跨版本 AST 保存，编辑器根据预览版本显示不可用值并保留原始配置。
- 扩展节点注册表、导入导出、插件管理和旧版技能字段映射。

## 发布内容

- `ProSkillAPI-R-1.3.0.jar`：包含主插件及全部已配置的 NMS 世代实现。
- 运行时依赖 `MCCore-3.0.6.jar`。
