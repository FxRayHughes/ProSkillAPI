# ProSkillAPI R-1.2.25

## 粒子跨版本兼容

- 技能编辑器将导入的旧版标量粒子转换为粒子 AST；导出始终保留 AST，不再绑定预览版本。
- 服务端按实际运行版本读取 AST 中的粒子映射；映射缺失或无效时播放白色 `CLOUD`，保存技能时保留原始 AST。
- 预览版本只需在编辑器主页设置一次。编辑器会提示当前预览版本中需要回退的粒子，并保留无法解析文件的原件。

## 升级说明

- 使用新版编辑器导出的粒子 AST 配置前，必须先升级到本版本插件；旧版插件只认识标量粒子。
- 运行时仍需 MCCore 3.0.6。

## 发布内容

- `ProSkillAPI-R-1.2.25.jar`：插件主 JAR，包含所有 NMS 世代实现。
