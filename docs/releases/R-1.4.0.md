# ProSkillAPI R-1.4.0

## 模块化战斗系统

- 增加 `Combat.modules` 独立开关，分别控制属性伤害缩放、暴击/闪避/韧性/吸血、战斗 Buff、职业友伤、仇恨和技能护盾。
- 关闭单个模块时，技能施法、技能事件和其他未关闭模块继续运行，不再通过一个总开关一刀切停用整个战斗流程。
- `Combat.modules.attributes` 只停止普通伤害、技能伤害和自然伤害的属性增伤/减伤，不影响法力、经验、饥饿和 Bukkit 实体属性同步。
- 暴击条件、闪避条件、护盾机制和仇恨目标选择器都会遵守对应模块开关，避免读取关闭模块留下的旧状态。

## 外部战斗系统接管

- `PhysicalDamageEvent`、`SkillDamageEvent` 和 `TrueDamageEvent` 保持可监听、可修改和可取消，外部战斗插件可以接管属性、暴击、防御和真实伤害结算，同时继续使用 SkillAPI 技能。
- 关闭仇恨模块时只清理 SkillAPI 本地快照和自身记录的在线嘲讽增量，不清空可能由其他战斗插件共享的 MythicMobs ThreatTable。
- 技能护盾关闭后会清空 SkillAPI 护盾层，后续真实伤害、技能伤害和 Bukkit 伤害按原始流程处理。

## 编辑器与配置

- 默认配置和编辑器配置夹具同步增加六个战斗模块开关及详细说明。
- 补齐模块边界、外部接管行为和兼容约束的 JavaDoc 与配置注释。

## 发布内容

- `ProSkillAPI-R-1.4.0.jar`：包含主插件及全部已配置的 NMS 世代实现。
- 运行时依赖 `MCCore-3.0.6.jar`。
