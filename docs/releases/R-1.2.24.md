# ProSkillAPI R-1.2.24

## 构建修复

- 恢复 NMS 各世代的完整 Spigot 服务端编译依赖，并补充 BuildTools 本地安装说明。
- 将 1.21.11 的坐标修正为 BuildTools 实际发布的 `1.21.11-R0.2-SNAPSHOT`。
- 在本地用 BuildTools 安装全部 12 个所需版本后，使用 Java 25 执行 `clean build`，完整构建成功。

## 发布内容

- `ProSkillAPI-R-1.2.24.jar`：插件主 JAR，包含所有 NMS 世代实现。
- `dragoncore.jar`：可选 DragonCore 集成模块。
- 运行时依赖 MCCore 3.0.6。完整 Spigot 服务端 JAR 只用于本地编译，不随插件分发。
