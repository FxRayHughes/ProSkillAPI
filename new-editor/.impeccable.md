## Design Context

### Users

Minecraft 服务器技能配置作者，需要反复编辑节点参数和检查技能执行路径。

### Brand Personality

专业、克制、清晰；以任务效率和可读性优先。

### Aesthetic Direction

用户指定参考 Evocation 编辑器和 UE 蓝图。使用 Mantine 深色工具界面，
中性灰画布配类别色节点，紧凑左右面板，小屏通过抽屉保留画布空间。

### Design Principles

- 控件优先采用 Mantine，图交互使用 React Flow。
- 用端口位置、文字和类别色共同表达语义。
- 参数编辑不能破坏持久化 ID 与接线关系。
- 图标按钮提供可访问名称和 Tooltip。
